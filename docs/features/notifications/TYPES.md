# Notification Types

V1 supports `DROP_LIKED`, `COMMENT_CREATED`, `COMMENT_REPLIED`, `DROP_REDROPPED`, `QUOTE_REDROP_CREATED`, `USER_FOLLOWED`, `FOLLOW_REQUEST_RECEIVED`, `FOLLOW_REQUEST_APPROVED`, `USER_MENTIONED`, `TRENDING_ACHIEVED`, `TOP100_ACHIEVED`, and `SYSTEM_ANNOUNCEMENT`. Rejections, saves, unfollows, self-actions, and mute state do not notify. Club and Chat type namespaces are future-only.
