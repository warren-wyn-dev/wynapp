# WYN Top 100 Creators

WYN Top 100 V1 means exactly the top 100 **public creators**. It is a periodic snapshot over a rolling **7-day** window, recomputed hourly. Private, restricted, suspended, banned, deletion-pending and deleted creators are excluded. Only engagement on eligible public Drops with `GLOBAL_PUBLIC` scope participates.

```
audience = 25*ln(1+distinctPublicEngagers)
engagement = 10*ln(1+uniqueLikes) + 14*ln(1+uniqueCommenters)
           + 18*ln(1+uniqueRedroppers) + 5*ln(1+uniqueCountedViewers)
activity = min(15, 3*eligibleActiveDays)
consistency = min(10, 2*daysWithEligiblePublicEngagement)
quality = min(15, 3*distinctEngagementTypes)
recency = 10*exp(-hoursSinceLatestEligibleDrop/36)
abusePenalty = min(60, 25*duplicateRatio + 20*burstFlag + 15*selfEngagementRatio)
score = audience + min(55,engagement) + activity + consistency + quality + recency - abusePenalty
```

Rows store rank, quantized score, `computed_at`, window start/end and ruleset version. Rank is deterministic by score descending then creator ID. Publication swaps the complete snapshot atomically; requests never calculate the ranking. Club-internal/private engagement is excluded without conversion or subtraction.
